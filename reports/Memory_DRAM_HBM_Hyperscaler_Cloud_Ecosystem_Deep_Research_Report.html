Together, the SanDisk–Kioxia JV commands >30% of global NAND flash wafer capacity, giving SNDK multi-billion-dollar fab scale at half the standalone R&D and cleanroom CapEx burden.

Instead of fabricating peripheral CMOS logic under the memory array (which degrades logic transistors during high-temperature NAND annealing), CBA fabricates the peripheral CMOS logic on a separate wafer at optimal logic temperatures and hybrid-bonds it face-to-face with the 218-layer 3D NAND cell wafer. This delivers a 50% increase in I/O interface speed (3.2–3.6 Gbps), 20% lower write power, and industry-leading bit density per square millimeter.

As HBM rises from 8% to >25% of global DRAM wafer starts, it creates an artificial supply famine in standard server DDR5 RDIMMs and LPDDR5X (MEM_DC_R0).
